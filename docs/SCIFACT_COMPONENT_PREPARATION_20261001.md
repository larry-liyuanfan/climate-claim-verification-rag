# Stage A component diagnosis — CPU implementation, not model evidence

This bounded package follows the negative semantic-policy comparison at
`99cd9ff707697ea395a9bc067f3ce91395071cdb`. It uses only the same twelve consumed
TRAIN claims. No new claim selection, remaining-TRAIN split, dev/test read,
training, real model call or Slurm submission is authorized here. This is not
an autonomous Agent or a deployment evaluation.

## Frozen source and input contract

The preparation entrypoint binds the original/new run hashes, paired score,
inference/scoring tar hashes, original corpus and all four tokenizer files.
It verifies the old source SHA, arm, route, claim identity and attempt zero.
Private raw text, IDs, selected gold, per-row inputs and targets remain on
Spartan. Inference slots and scoring targets occupy separate directories:
dataflow separation, **not** an OS sandbox against the shared account.

| Component | Fixed input / target selection | Maximum diagnostic calls |
|---|---|---:|
| Screening | Original-G `fixed_rerank.visible_attempts[0].visible`, aliases deduplicated in first-occurrence order; restore original full abstracts | 12 |
| Relation | Minimum **numeric** gold doc ID for nine evidence claims; minimum official `cited_doc_ids` for three NEI controls; no label in input | 12 |
| Oracle rationale | Same selected gold document, explicitly correct relation, original sentence IDs; no gold alternatives in input | 9 |

The candidate set is neither top20 nor requested top5. An alias with no actually
displayed sentence is not backfilled. Alias/document uniqueness, full-source
SHA256 of compact JSON `[title, sentences]`, sentence index/text hashes and
ordered identities must agree across trace, trace actual observation, initial
context and first generation diagnostics. Full-abstract restoration is an
explicit input change, not an old-prompt replay.

The three NEI contexts are **official-code-derived controls**, not independent
human document-pair negative annotations. Missing cited context, conflicting
target labels, missing source or no complete <=3-sentence rationale produces a
preparation gap; no easier document is substituted. Each full system/schema/user
prompt is counted with the frozen tokenizer, no thinking, input 8192/output512,
120 seconds, one attempt, no repair/retry. Overlong full abstracts are preserved
and marked over-budget; there is no sentence clipping or gold-aware packing.

The compact protocol template is generated by `protocol()` and binds the prompt
bytes and model/tokenizer manifests. Per-slot schema/input/rendered-prompt hashes
are generated only by successful real-tokenizer preparation. The final private
protocol additionally binds source, selected data, inputs, scoring and coverage.

## Scoring and localization

Screening separately counts absent gold documents, available-gold omissions and
selected **unannotated** documents. Unannotated does not establish semantic
irrelevance. NEI gold recall is null, not one. Screening correctness is conditional
on the supplied pool, never whole-corpus retrieval success.

Relation reports nine gold-document cases and three derived NEI controls
separately, retaining strata on failed and preparation-gap rows. Explicit
abstention, NEI classification, schema failure and provider failure differ.
All planned/attempted/valid/failure denominators remain visible; invalid rows
cannot carry successful or abstained scores. Scoring joins require identical
input, prompt, schema and packing identities, and preserve claim/target-doc keys.

Rationale scoring treats alternatives as **OR**, never a mandatory union. Set
equivalence is accepted regardless of order; only the original first three
output indices determine first3 credit. Report any-alternative completion,
first3 credit, exact-any-alternative, unannotated extras and redundancy separately.
No <=3 alternative means contract-unreachable, not model failure. First3 credit
with extra sentences is still flagged as overselection, not minimal-rationale
success.

Same-claim/same-target pairs localize relation, sentence selection or joint
grounding candidates. Oracle success with poor screening suggests document
discrimination/negative-label quality. Coverage, formatting and provider gaps
are separated first. These are hypotheses, not proof an adapter fixes the system;
no result automatically authorizes action SFT or establishes Agent benefit.

## Durable fixture interface and reproduction

The runtime **rejects non-fixture providers**. No new real provider/grammar or
GPU operator is implemented. The old action grammar is not appropriate for the
three new schemas and must not be silently reused.

Each fixture slot has an exclusive directory, initialized record and durable
attempt-started reservation before `generate`. Failure to write the reservation
makes zero calls. Raw response and partial known cost are persisted before
parsing; missing cost is unknown, not zero. Completed-write failure retains an
in-memory partial report and the already-durable response. Reusing a slot path
fails, and an interrupted started slot cannot be mistaken for unattempted work.

```powershell
python -m pytest tests/test_scifact_components.py -q
python scripts/check_scifact_components.py --output artifacts/component-fixtures-NEW
python -m ruff check src/climate_rag/scifact_component_*.py scripts/prepare_scifact_components.py scripts/check_scifact_components.py tests/test_scifact_components.py
python -m mypy --follow-imports=silent src/climate_rag/scifact_component_*.py scripts/prepare_scifact_components.py scripts/check_scifact_components.py
```

The four CLI examples are **scripted synthetic fixtures**, using an explicitly
labeled character counter, not Qwen tokenization or real-provider preflight.
The 52-test targeted suite includes an end-to-end frozen-source preparation
fixture and never reads real data or runs a model. Historical full-suite counts
remain historical; they are not promoted to this revision.

Real private CPU preparation, when the exact frozen tokenizer runtime is
available (no weights):

```bash
PYTHONPATH="$SOURCE/src" USE_TORCH=0 USE_TF=0 \
python "$SOURCE/scripts/prepare_scifact_components.py" \
  --source-git "$EXACT_SOURCE_GIT" \
  --tokenizer-dir "$FROZEN_TOKENIZER_DIRECTORY" \
  --output "$ROOT/posthoc/scifact-component-preparation-${EXACT_SOURCE_GIT:0:12}"
```

`SOURCE` must be an exact Git archive with its expanded `SOURCE_REVISION`; the
archive and extracted bytes must be verified before this command. Output is
exclusive. The public compact contains only explicit source hashes/counts,
coverage and packing ranges, no identifiers or text. This package's real-input
preparation state is recorded in the accompanying receipt, not inferred from
the passing synthetic fixture.

## Future release, hard stop

At most 33 diagnostic +4 real synthetic preflight =37 single-attempt calls.
Failing/missing cases are not replaced to fill a quota. Proposed ceiling is one
A100, 8 CPU, 32 GiB, 100 minutes, serial/no-requeue: 37*120 seconds plus 1560
seconds staging/loading allowance. This conservative ceiling is a proposal, not
approved resources or an ETA; the previous 52-call arms took 629/627 seconds.

A future separately reviewed operator must verify the frozen source, private
protocol/input hashes and new-schema real-provider preflight, then use
`sbatch --test-only` before a single bounded submission. There is deliberately
no runnable GPU submission command in this CPU package. Stop for that exact-hash
release; do not open remaining TRAIN, official dev or frozen test, train any
adapter, alter claims or change the current resume.
